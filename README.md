# 🚗 FullTorque

### Sistema de gerenciamento para centros automotivos

O **FullTorque** é um sistema desenvolvido como **Trabalho de Conclusão de Curso (TCC)** pelo meu grupo durante o curso Técnico em Desenvolvimento de Sistemas.

O projeto foi desenvolvido com o objetivo de aplicar, na prática, os conhecimentos adquiridos durante o curso, envolvendo desenvolvimento de sistemas, banco de dados, organização de informações e desenvolvimento de uma solução voltada para o gerenciamento de um centro automotivo.

🏆 **Reconhecimento:** o projeto recebeu **a melhor nota da sala entre os trabalhos de conclusão de curso**.

---

## 📌 Sobre o projeto

O FullTorque foi desenvolvido pensando nas necessidades de um centro automotivo, buscando centralizar e organizar informações relacionadas aos serviços realizados pela empresa.

A proposta foi transformar processos que poderiam ser realizados de maneira manual em uma solução informatizada, facilitando o gerenciamento das informações e proporcionando uma experiência mais organizada para os usuários do sistema.

Este projeto também representa uma das principais experiências práticas adquiridas durante minha formação como **Técnico em Desenvolvimento de Sistemas**.

## 🚀 Como executar o projeto

### 1. Pré-requisitos

Para executar o projeto localmente, é necessário ter instalado:

* [XAMPP](https://www.apachefriends.org/)
* PHP
* MySQL
* Navegador web

### 2. Clonar o repositório

```bash
git clone https://github.com/iago-gustavo-vieira/FullTorque.git
```

### 3. Mover o projeto

Coloque a pasta do projeto dentro do diretório:

```text
C:\xampp\htdocs\
```

### 4. Iniciar o XAMPP

Abra o XAMPP e inicie:

* Apache
* MySQL

### 5. Configurar o banco de dados

Crie o banco de dados no **phpMyAdmin** e importe o arquivo de estrutura `.schema.sql` disponibilizado no projeto.

> Por questões de segurança, informações de conexão, senhas e configurações específicas do ambiente local não são disponibilizadas no repositório público.

### 6. Executar

Depois de configurar o ambiente, acesse o projeto pelo navegador através do endereço local correspondente ao diretório do sistema.
