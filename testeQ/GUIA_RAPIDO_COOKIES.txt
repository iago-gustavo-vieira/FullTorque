┌──────────────────────────────────────────────────────────────────┐
│ 🧪 COMO TESTAR                                                   │
└──────────────────────────────────────────────────────────────────┘

TESTE RÁPIDO:
1. Abra: http://localhost/FullTorque/testeQ/teste-cookies.html
2. Siga as instruções na página
3. Verifique todos os itens do checklist

TESTE MANUAL:
1. Limpe cookies do navegador (F12 > Application > Cookies)
2. Acesse qualquer página do site
3. Banner deve aparecer após 0.5 segundos
4. Clique em "Aceitar" ou "Recusar"
5. Banner desaparece
6. Recarregue a página
7. Banner NÃO deve aparecer novamente

TESTE DE PERSISTÊNCIA:
1. Limpe cookies
2. Acesse home.php → Banner aparece
3. NÃO clique no banner
4. Navegue para index.php → Banner aparece novamente
5. Navegue para veiculos.php → Banner aparece novamente
6. Clique em "Aceitar"
7. Navegue entre páginas → Banner NÃO aparece mais

│ 🐛 PROBLEMAS COMUNS                                              │
└──────────────────────────────────────────────────────────────────┘

BANNER NÃO APARECE:
→ Limpe cookies do navegador

→ Teste em aba anônima

ESTILOS NÃO APLICADOS:
→ Limpe cache (Ctrl+Shift+Del)
→ Recarregue com Ctrl+F5
→ Verifique conflitos de CSS
